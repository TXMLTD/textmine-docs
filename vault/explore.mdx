Explore helps you investigate a set of Vault documents without opening them one by one. Choose the documents you want to review, ask a question in plain language, and get an answer with clear findings, tables, and charts.

## Choose your document scope

1. Open **Vault** and select **Explore**.
2. Search or browse the documents available in your Vault.
3. Select the documents you want to include, or use **Select all** and **Clear** to manage the selection quickly.
4. Use **Selected only** to check exactly which documents are in scope.
5. Turn on **Include Vault tags and extracted information** when you want Explore to use structured data alongside the document text.

The selected document count is shown at the top of the page. Use **Choose documents** to change the scope at any time.

## Ask a question

Type a question in the prompt box using everyday language. Explore works well for questions such as:

- Find all consistent and inconsistent terms
- Compare payment terms
- Summarise key clauses
- Find auto-renewal clauses

You can edit the question and ask a follow-up when you want to refine the result. Saved views can keep a useful document scope and prompt together so your team can return to the same analysis later.

## Review the answer

Explore presents the answer in sections that are easy to scan:

- **Key findings** highlight the most important patterns and differences.
- **Tables** organise extracted values so you can compare documents directly.
- **Charts** make trends and outliers easier to spot.
- **Source details** help you trace the answer back to the documents in scope.

Download a table as **CSV** or a chart as **PNG** when you need to share the result or use it in another document.

## Share a saved view

Save an analysis that you expect to reuse. Depending on your Vault permissions, you can share the view with other people in the Vault. Shared views preserve the document scope and question so everyone starts from the same context.

## Tips for better results

- Keep the document scope focused when you need a precise comparison.
- Name the documents or fields you care about in the question.
- Include Vault tags and extracted information for questions about structured values.
- Review important findings against the source documents before relying on them.

Explore is designed to help you find patterns quickly; it does not change the documents you select. AI-generated answers can make mistakes, so always check important information against the source documents.
